# Лендинги Aleron Academy для Тильды — инструкция

Подготовлено 20.11.2026. Для каждой страницы есть два файла для блока **T123 (Embed HTML code)**.

| Страница | Файл «сразу» (фото внутри) | Лёгкий файл (фото ссылками) | Фото |
|---|---|---|---|
| Вебинар → fire-proof.co.uk/webinar | `webinar/T123_webinar_inline.html` (~410 КБ) | `webinar/T123_webinar.html` (~36 КБ) | `webinar/images/` |
| Курсы → fire-proof.co.uk/courses | `courses/T123_courses_inline.html` (~435 КБ) | `courses/T123_courses.html` (~46 КБ) | `courses/images/` |

Файл «сразу» работает без подготовки. Лёгкий загружается быстрее, но для него фото нужно выложить на хостинг: GitHub Pages (план с автообновлением) или любой другой.

## Как поставить страницу

1. Тильда → проект fire-proof.co.uk → **Создать страницу** (пустая).
2. **Настройки страницы:**
   - адрес: `webinar` или `courses`;
   - заголовок и описание (SEO и соцсети) — из таблицы ниже;
   - шапку и подвал сайта оставить включёнными.
3. Добавить блок **T123**: Библиотека блоков → Другое → T123. Открыть **Контент**, удалить всё в поле и вставить **весь** текст из нужного файла.
4. **Опубликовать.** В редакторе блок выглядит как код — это нормально: он работает только на опубликованной странице.
5. Открыть страницу и проверить её на телефоне и на компьютере.

**Лёгкий файл:** перед вставкой заменить в нём `__IMG_BASE__` (поиск и замена во всём файле) на адрес папки с фото. Адрес должен заканчиваться на `/`, например `https://<github-user>.github.io/aleron-landings/webinar/images/`.

## Что изменено по сравнению с версией для предпросмотра

- **Стили изолированы.** Все стили работают только внутри `<div id="aleron-lp">`, поэтому не ломают шапку, подвал и другие блоки сайта. Проверено на тестовой странице с «враждебными» стилями.
- **Шапка.** Своей шапки с логотипом нет — используется шапка сайта. К якорям добавлен отступ, чтобы фиксированное меню не закрывало заголовки.
- **Meta Pixel.** На fire-proof.co.uk пиксель 1476822027723349 уже загружается сайтом (через GTM / Тильду). Наш блок второй раз его **не подключает** и баннер cookies **не показывает**. Все события из `Pixel_events_plan.md` (CTAClick, ViewContent, InitiateCheckout, CompleteRegistration, Lead и др.) уходят в уже загруженный пиксель. Повторного PageView нет.
- **Режим проверки.** Если добавить к адресу `?pxdebug=1`, события будут видны в консоли браузера.

## Перед запуском рекламы

1. **Формы → academy@aleron.co.uk.** Заявки с обеих страниц уходят письмом через сервис FormSubmit. **Его нужно один раз активировать.** Опубликуйте страницу, отправьте с неё одну тестовую заявку, откройте в ящике academy@aleron.co.uk письмо от FormSubmit и нажмите *Activate Form*. До активации посетитель увидит ошибку, и заявка потеряется. Проверьте также папку «Спам». Если надёжнее нужен Web3Forms: получите на web3forms.com ключ на academy@aleron.co.uk, пришлите его мне — я впишу его в `WEB3FORMS_KEY`. Какой бы сервис ни использовался, его нужно упомянуть в политике конфиденциальности как обработчика данных.
2. **Cookies и согласие.** Сейчас сайт загружает Meta Pixel, Google Analytics/Ads, Clarity и Яндекс Метрику **сразу, без согласия** посетителя. Для UK (PECR / UK GDPR) нужен баннер согласия на уровне всего сайта: в Тильде — Настройки сайта → Cookies, или через GTM Consent Mode. Это касается всего fire-proof.co.uk, не только лендингов.
3. **Ссылки на Terms / Cancellation / Complaints** в подвале страницы курсов появятся, когда эти страницы будут опубликованы.
4. **Ссылка на вебинар** на странице курсов больше не нужна: блок с вебинаром удалён.
